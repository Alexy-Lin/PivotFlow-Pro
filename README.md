# PivotFlow Pro

Excel 数据透视图表生成器 — 基于 Python 的桌面 GUI 工具，支持多文件导入合并、自动日期维度拆解、11 种图表类型一键生成。

## 功能特性

**数据导入**
- 多选 Excel 文件，按列名自动合并（不同列自动补齐，缺失留空）
- 支持增量追加导入，多次导入自动拼接
- 自动检测日期列，追加 周 / 月 / 季度 维度列
- 合并结果自动保存到 `temp/`，可随时另存副本

**图表生成**
- **11 种图表**：堆积柱形图、分组柱形图、横向堆积条形图、横向分组条形图、折线图、面积图、饼图、环形图、散点图、热力图、箱线图
- **9 种配色** + **5 种 seaborn 主题**
- 图表标题、字号（标题/X轴/Y轴/图例）均可独立调整
- 图例可选，支持不分组直接对比

**数据展示**
- 数据预览表格（斑马纹、行列统计）
- 透视表展示标签页
- 图表嵌入展示

**导出**
- 透视表导出 Excel
- 图表导出 PNG / JPEG / PDF 高清图片

**交互**
- 键盘快捷键：`Ctrl+O` 导入、`Ctrl+G` 生成、`Ctrl+E` 导出 Excel、`Ctrl+S` 导出图片
- 支持拖拽 Excel 文件到窗口

## 快速开始

### 环境要求

- Python 3.8+
- 依赖首次运行自动安装（pandas / matplotlib / seaborn / openpyxl）

### 启动

```
双击 run_pivot_gui.bat
```

或

```bash
python create_pivot_gui.py [Excel文件路径]
```

## 使用步骤

1. 点击 **导入数据**，选择一个或多个 Excel 文件
2. 如需追加数据，再次点击导入即可（新行向下拼接，新列自动补齐）
3. 在 **列映射** 中选择 X 轴、Y 轴、图例对应的列
4. 在 **图表设置** 中选择图表类型、主题和配色
5. 点击 **生成透视图**
6. 切换标签页查看数据预览 / 透视表 / 图表
7. 使用 **保存** 另存合并数据，或使用 **导出 Excel / 导出图片** 保存结果
8. 点击 **关闭** 清空数据库，恢复初始状态

## 项目结构

```
├── create_pivot_gui.py    # GUI 主程序（UI + 交互逻辑）
├── chart_engine.py        # 图表生成引擎（11 种图表类型）
├── data_importer.py       # 数据导入模块（多文件合并、增量追加）
├── config.py              # 共享常量（主题、配色、UI 颜色）
├── utils.py               # 工具函数（依赖检查、字体配置、日期富化）
├── run_pivot_gui.bat      # 启动脚本
├── temp/                  # 临时文件（自动生成，gitignore）
└── .gitignore
```
